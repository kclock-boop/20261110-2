바른규정 - PC 인사규정 관리 프로그램

1. 압축파일을 PC의 원하는 폴더에 모두 풀어 주세요.
2. index.html을 더블클릭하여 Chrome 또는 Edge로 열어 주세요.
3. 예시 규정 8개가 표시됩니다. 예시는 실제 회사 규정이 아닙니다.
4. 새 규정 등록에서 규정명, 분류, 담당부서, 시행일, 상태, 본문을 입력합니다.
5. 기존 규정은 규정명을 클릭하고 개정하기를 누릅니다.
6. 개정 사유를 입력하여 저장하면 이전 원문이 개정 이력에 보관됩니다.
7. 백업·설정에서 백업 다운로드를 눌러 JSON 파일을 별도 보관합니다.
8. 다른 PC에서는 이 프로그램을 열고 백업·설정 > 백업 파일 선택으로 복원합니다.

예: 휴가 규정 개정
규정 클릭 → 개정하기 → 내용 수정 → 개정 사유 입력 → 저장
이전 버전은 규정 상세의 개정 이력에서 확인합니다.

지원 기능
- 규정 등록, 본문 검색, 분류/상태별 조회, 정렬
- 즐겨찾기, 시행 일정, 폐지 상태 보관
- 개정 사유 및 이전 버전 기록
- CSV 목록 내보내기, TXT 원문 저장, JSON 전체 백업·복원

알아두세요
- 설치 및 인터넷 연결이 필요 없는 HTML 프로그램입니다. EXE 설치파일은 아닙니다.
- 로그인 없이 열리므로 해당 PC에 접근할 수 있는 사람은 자료를 열람할 수 있습니다.
- 데이터는 HTML 파일 내부가 아니라 현재 브라우저의 로컬 저장공간에 저장됩니다.
- HTML 파일만 복사해서는 입력 자료가 함께 옮겨지지 않습니다. 반드시 백업 후 복원하세요.
- 같은 파일 위치와 같은 브라우저로 사용하세요. 파일 위치나 이름을 바꾸기 전에도 백업하세요.
- 시크릿 모드, 브라우저 데이터 삭제, 저장공간 차단 시 자료가 유지되지 않을 수 있습니다.
- 브라우저의 파일 URL 저장 정책에 따라 저장이 제한될 수 있습니다. 경고가 나타나면 실제 자료를 입력하지 마세요.
- 자료의 장기 보관을 위해 사용 후 백업 파일을 다운로드해 주세요.
- 직원별 권한, 결재, 공동 편집, 여러 기기 자동 동기화 기능은 없습니다.
- 시행일이 되어도 상태는 자동 변경되지 않으므로 담당자가 확인하여 변경하세요.
- 실제 회사 규정은 사내 승인 및 필요한 검토를 거쳐 등록하세요.

저장 방식
인터넷 서버로 규정 자료를 전송하지 않습니다. 외부 글꼴·CDN을 사용하지 않습니다.
프로그램 코드와 화면에 필요한 기능은 index.html에 모두 포함되어 있습니다.
